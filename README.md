# MLaaS-Lite
Multi-Tenant, Self-service Machine Learning Platform is a product that allows data scientists to train, deploy, and manage models through a UI.


### Day 3
Goal is to stop manually typing kubectl commands for every change. ArgoCD is installed to manage each cluster and Nginx Ingress for accessing applications via a browser and not just port-forwarding.

### Objectives
    i. Enable Ingress (Traffic routing)
    ii. Install and Setup ArgoCD (GitOps controller)
    iii. Deploy MinIO (Object Storage) using GitOps
